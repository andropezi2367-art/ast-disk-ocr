# Security and safety reporting

Please report security or patient-safety-relevant problems through a private GitHub
security advisory when available. Do not attach patient images, identifiers,
credentials, proprietary rule tables, or licensed model weights to a public issue.

Examples of safety-relevant defects include:

- an ambiguous OCR result being marked accepted;
- a low-confidence result bypassing review;
- conflicting rotations being collapsed into one answer;
- catalog metadata being interpreted as a breakpoint rule;
- output being represented as a clinical S/I/R result.

This alpha project has no clinical-use or regulatory assurance.
