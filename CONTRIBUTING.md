# Contributing

Contributions are welcome when they preserve the conservative review boundary.

Before opening a pull request:

1. add or update tests;
2. run `pytest -q` and `ruff check .`;
3. do not commit clinical images, patient data, proprietary catalogs, credentials,
   or model weights without documented redistribution rights;
4. describe the dataset provenance and split strategy for any performance claim;
5. report uncertain and rejected cases, not only accepted-case accuracy.

Code contributions are licensed under Apache-2.0.
